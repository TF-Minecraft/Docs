# AdvancedCrafting

[Source repository](https://github.com/TF-Minecraft/AdvancedCrafting) · [All projects](../../README.md)

AdvancedCrafting provides crafting stations, ingredient conversion, smithing, alloy discovery, MMOItems stat calculation, and item provenance.

## Build and configuration

Use Java 25 and follow the [source README](https://github.com/TF-Minecraft/AdvancedCrafting/blob/main/README.md) for Maven builds, TLibs setup, private dependency access, and runtime installation.

- [Maven dependencies and packaging](https://github.com/TF-Minecraft/AdvancedCrafting/blob/main/pom.xml)
- [Plugin descriptor and default configuration](https://github.com/TF-Minecraft/AdvancedCrafting/tree/main/src/main/resources)
- [Source import provenance](https://github.com/TF-Minecraft/AdvancedCrafting/blob/main/SOURCE.md)

## Builds and releases

See the [shared pipeline guide](../../PIPELINES.md) for dated development artifacts and tag-triggered draft releases. Server-specific recipes and schemes must be supplied in the plugin's configuration; release publication does not deploy them.
